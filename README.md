# Student Performance Prediction

## About the Project
This project uses Machine Learning to predict a student's Maths marks based on Science marks, English marks, and Attendance.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Linear Regression

## Features
- Creates student marks data
- Splits data into training and testing sets
- Trains a Linear Regression model
- Calculates prediction error
- Predicts Maths marks for a new student
